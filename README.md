## 🚀 Getting Started

### Prerequisites

* Python 3 installed on your computer.
* Git installed on your computer.
* Visual Studio Code with the Python and Jupyter extensions, or another compatible Jupyter environment.

### Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/ShreyaGade1503/python-fundamentals.git
cd python-fundamentals
```

### Install Dependencies

Install Jupyter Notebook:

```bash
pip install notebook
```

For notebooks that use the `requests` library, install it with:

```bash
pip install requests
```

### Run the Notebooks

1. Open the repository folder in Visual Studio Code.
2. Open any `.ipynb` notebook.
3. Select a Python kernel.
4. Run the cells to explore the code and practice the concepts.

Some notebooks or projects may require additional libraries.
